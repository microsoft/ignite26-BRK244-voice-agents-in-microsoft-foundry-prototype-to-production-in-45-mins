# Multilingual conversations and code-switching

Open [notebook 03](../src/notebooks/03_multilingual_code_switching.ipynb).
Run setup once, then run the recording cell with `case_index` set to 0, 1, and 2.
Read the displayed utterance aloud when recording starts.

## Exercise objective

Compare separate-language turns and a code-switched turn using languages
supported by the selected deployment. Do not equate prompt instructions with a
guarantee of speech recognition, language identification, or pronunciation quality.

Use neutral synthetic prompts such as:

- "Explain how a rainbow forms in one sentence."
- "Explica en una frase como se forma un arcoiris."
- "Explain a rainbow briefly, y termina en espanol."

## Record your observations

Record the requested language, observed response language, intelligibility, and
any missed switch. Listen to the audio rather than using transcript text alone
as evidence of pronunciation or speech quality.

Automatic scoring and the focused tracing and evaluation segment are deferred
to a later increment. Return to the [attendee path](README.md).
